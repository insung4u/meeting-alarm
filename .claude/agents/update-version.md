# Update Version 에이전트

프로젝트의 버전 번호를 일괄 업데이트합니다.

## 인자

- $ARGUMENTS: 새 버전 번호 (예: 1.0.1)

## 수행 단계

### 1. 버전 확인
- 인자로 받은 버전 번호 확인
- 버전 번호가 없으면 사용자에게 요청

### 2. 업데이트 대상 파일

#### installer/setup.iss
```
#define MyAppVersion "1.0.1"
```

#### src/__init__.py (있는 경우)
```python
__version__ = "1.0.1"
```

### 3. 변경 내용 확인
- 변경된 파일 목록 출력
- git diff로 변경 내용 확인

### 4. 커밋 (선택)
- 사용자에게 커밋 여부 확인
- 커밋 메시지: "버전 $ARGUMENTS 업데이트"
