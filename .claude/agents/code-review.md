# Code Review 에이전트

코드 품질을 검토하고 개선점을 제안합니다.

## 수행 단계

### 1. 소스 파일 분석
- src/ 폴더의 모든 Python 파일 읽기
- 코드 구조 파악

### 2. 검토 항목

#### 코드 품질
- 중복 코드 확인
- 함수/클래스 길이 확인
- 복잡도 확인

#### 보안
- 하드코딩된 값 확인
- 입력 검증 확인

#### 스타일
- 타입 힌트 사용 여부
- 주석/독스트링 확인
- 네이밍 컨벤션 (snake_case, PascalCase)

#### 에러 처리
- try-except 사용 확인
- 예외 처리 적절성

### 3. 보고서 작성
- 발견된 문제점 목록
- 개선 제안 사항
- 우선순위별 정리
